## Design System Reference

### Color Palette
| Role | Color | Hex |
|------|-------|-----|
| Primary (Navy) | Dark navy blue | `#11154e` |
| Background (Cream) | Warm off-white | `#f9f7f4` |
| Accent 1 (Teal) | Primary accent | `#0e7b8c` |
| Accent 2 (Sage) | Secondary accent | `#8fbc9f` |
| Gradient | Teal → Sage | `#0e7b8c` → `#8fbc9f` |
| Text Secondary | Muted navy | `#3d4270` |
| Text Tertiary | Light gray-blue | `#9499bb` |
| Card Border | Warm gray | `#e8e0d6` |

### Typography
| Element | Font | Weight | Size (guidance) |
|---------|------|--------|-----------------|
| Cover headline | Poppins | 700 | 72–96pt |
| Slide titles | Poppins | 700 | 36–42pt |
| Card headlines | Poppins | 600 | 24–28pt |
| Body text | DM Sans | 400 | 18–20pt |
| Stats/numbers | Barlow Condensed | 700 | 48–72pt |
| Labels/captions | Poppins | 600 | 12–14pt, uppercase, tracked |
| Source citations | DM Sans | 400 | 12pt, Text Tertiary color |

### Recurring Elements
- **Card style:** White background, 1px border (`#e8e0d6`), 16px border-radius, subtle shadow
- **Gradient accent bar:** 3px height, teal→sage gradient, used as top border on cards or section dividers
- **Progress tracker:** Horizontal pill bar showing trend position (1-5), active state filled with teal
- **eLearningU logo:** Bottom-right corner on cover/closing slides

### SLIDE 6: Trend 4 — Sustainability = Market Access

**Layout:** Two-tier explanation with flow diagram

**Header Area:**
| Element | Content |
|---------|---------|
| Progress tracker | Position 4 filled |
| Trend number | `TREND 04` |
| Headline | `Sustainable Procurement Becomes Mandatory` |
| Subhead | `— And It Affects Canadian Exports` — DM Sans 400, 18pt, Text Secondary |

**Regulation Cards (top row, 3 cards):**

| Card | Region | Regulation | Requirement |
|------|--------|------------|-------------|
| 1 | EU | CSRD | Supply chain environmental reporting |
| 2 | EU | CSDDD | Identify adverse impacts in supplier networks |
| 3 | France | AGEC Law | Restricts single-use plastics in hospitality |

**Card Style:**
- Small cards (equal width, 3-up)
- Flag or region icon at top
- Regulation name: Poppins 700, 16pt, navy
- Requirement: DM Sans 400, 13pt, Text Secondary

**Flow Diagram (bottom half):**

Visual showing verification chain:
```
[EU/Asia Travel Trade Partner] → verifies → [Canadian Operator] → needs → [Documentation]
     Tour operators                           Hotels, experiences         Certifications
     OTAs                                                                 Sustainability data
     Travel agencies
```

**Diagram Style:**
- Horizontal flow, left to right
- Three nodes connected by arrows
- Each node: Rounded rectangle, icon + label
- Arrows: Teal, with small label above (`"must verify"`, `"requires"`)
- Use dotted line or X mark to show "excluded" path for operators without documentation

**"Why It Matters" Callout Box:**
- Position: Bottom or right side
- Style: Teal background at 10% opacity, teal left border (4px)
- Headline: `Why It Matters for Canadian DMOs` — Poppins 600, 14pt
- Body: `This is no longer about guest preferences — it's about market access. Operators without documentation risk exclusion from international distribution.` — DM Sans 400, 14pt

**Source Footer:**
`Source: Hospitality Net, June 2026`

## Animation Guidance (if animated/video)

| Slide | Animation |
|-------|-----------|
| Cover | Headline words stagger in (0.2s delay each); image subtle Ken Burns |
| Big Picture | Cards fade in sequentially (0.15s stagger) |
| Trend slides | Progress tracker fills; main content fades in; callouts pop |
| Actions | Numbers count up or items stagger in from left |
| Nothing Else | Icons scale up from 0 with slight bounce |
| Closing | Fade in from black; logo last |

**Timing:** Keep animations subtle and fast (0.3-0.5s). This is a professional briefing, not a motion graphics piece.
